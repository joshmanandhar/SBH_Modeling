# IPUMS Geographic Level 1 Lookup Table

Lookup table mapping IPUMS geographic level 1 codes to labels.

## Usage

``` r
geolev1_lookup_ipums
```

## Format

A data frame with 3 columns:

- Country:

  Country name

- Label:

  Administrative unit label

- Geolev1:

  IPUMS geographic level 1 code

## Source

IPUMS International

SBHModeling

Purpose

This is a package created to work on obtaining mortality rate estimates and uncertainty from summary birth history (SBH) data to be used in small area estimation (SAE) as area-level covariates (i.e. for the Fay-Herriot model). This is under the supervision of Prof. Jon Wakefield for Josh Manandhar’s independent study work.

  • The URL to the GitHub (i.e., the source code) is: https://github.com/joshmanandhar/SBH_Modeling
  • The URL to the Pkgdown webpage is: (https://joshmanandhar.github.io/SBH_Modeling)

How to install

This package is called SBHModeling. To install, run the following code (in R):

library(devtools)
devtools::install_github("joshmanandhar/SBHModeling")

Upon completion, you can run the following code (in R):

library(SBHModeling)

Examples/walkthroughs can be found in the vignettes folder (files with DEMO in the name)

Dependencies

The package depends on the following packages: dplyr, tidyr, tidyverse, ggplot2, readxl, patchwork, stats
